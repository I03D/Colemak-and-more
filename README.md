# Использование:
| Горячие клавиши: | Функция: |
| :---: | --- |
| Alt+l | Раскладка en_col |
| Alt+. | Раскладка en |
| Alt+; | Раскладка ru |
| Alt+k | Закрыть активное окно (будьте осторожны) |
| Win+j или Win+; | "Листать" окна влево/вправо как при Alt+Tab или Shift+Alt+Tab |
| Alt+, | [Mouseless](https://github.com/jbensmann/mouseless)-подобный режим: клавиши j, k, l и ; двигают курсор (навигация vim-like); w и e эмулируют колёсико мыши; f и d - левая и правая кнопки мыши; a - замедлить движение (более точное положение курсора); s - прекратить клавиатурное управление курсором; v - эмуляция нажатия на колёсико мыши |
| Alt+j | Включить выбор из 16 положений курсора (после выбора включится [Mouseless](https://github.com/jbensmann/mouseless)-подобный режим для уточнения положения; см. горячую клавишу Alt+,) |
| Alt + u, i, o или p | Эмуляция стрелок: ← ↓ ↑ → |
| Alt + 8, 9, 0 или - | Эмуляция функций home, pgDown, pgUp и end (снова vim-подобная навигация) |
| Alt + z, x, c или v | Звук: добавить 2, убавить 2, установить на 12 и установить на 0 |
| Alt+n | Заблокировать сессию Windows (выполняет Win+L) |

# Установка:
Могут потребоваться установленный язык/интерпретатор Python (https://www.python.org/downloads/windows/) и библиотеки PyQt5 и psutil:

pip install pyqt5
pip install psutil

Запустить файл **"Setup Colemak-and-more.exe"** и выполнить установку.

# Добавление в автозагрузку:

## Через папку автозагрузки:
1. Открыть **"Выполнить"**: нажать **Win+R** или набрать **"run" или "выполнить"** в меню Пуск.
2. Набрать **"shell:startup"**.
3. Нажать **Enter** / **"ОK"**.
4. Добавить в открывшуюся папку **ярлык Colemak-and-more**: перетащить **Colemak-and-more.exe**, зажав правую кнопку мыши, либо в контекстном меню выбрать **"Создать" > "Ярлык"** и пройти инструкции мастера создания (выбрать файл **Colemak-and-more.exe** и имя для ярлыка на следующем шаге).

## Через планировщик заданий Windows:
**Параметры запуска**:  C:\Users\ **(user)** \Desktop\Colemak-and-more-main\Colemak-and-more.exe  (путь к Colemak-and-more)
