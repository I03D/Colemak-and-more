# Использование:
| Горячие клавиши: | Функция: |
| --- | --- |
| Alt+l | Раскладка en_col |
| Alt+. | Раскладка en |
| Alt+; | Раскладка ru |
| Alt+, | [Mouseless](https://github.com/jbensmann/mouseless)-подобный режим: клавиши j, k, l и ; двигают курсор (навигация vim-like); w и e симулируют колёсико мыши; f и d - левая и правая кнопки мыши; a - замедлить движение (более точное положение курсора); s - прекратить клавиатурное управление курсором |
| Alt+j | Включить выбор из 16 положений курсора (после выбора включится [Mouseless](https://github.com/jbensmann/mouseless)-подобный режим для уточнения, см. горячую клавишу Alt+,) |


# Установка:
Могут потребоваться установленный язык/интерпретатор Python (https://www.python.org/downloads/windows/) и библиотека PyQt5:

pip install pyqt5
