# Использование:
| Горячие клавиши: | Функция: |
| --- | --- |
| Alt+l | Раскладка en_col |
| Alt+. | Раскладка en |
| Alt+; | Раскладка ru |
| Alt+k | Закрыть активное окно (будьте осторожны) |
| Alt+, | [Mouseless](https://github.com/jbensmann/mouseless)-подобный режим: клавиши j, k, l и ; двигают курсор (навигация vim-like); w и e эмулируют колёсико мыши; f и d - левая и правая кнопки мыши; a - замедлить движение (более точное положение курсора); s - прекратить клавиатурное управление курсором; v - эмуляция нажатия на колёсико мыши |
| Alt+j | Включить выбор из 16 положений курсора (после выбора включится [Mouseless](https://github.com/jbensmann/mouseless)-подобный режим для уточнения, см. горячую клавишу Alt+,) |
| Alt + u, i, o или p | Эмуляция стрелок: ← ↓ ↑ → |
| Alt + 8, 9, 0 или - | Эмуляция функций home, pgDown, pgUp и end (снова vim-подобная навигация) |
| Alt + z, x, c или v | Звук: добавить 2, убавить 2, установить на 12 и установить на 0 |
| Alt+n | Заблокировать сессию Windows (выполняет Win+L) |

# Установка:
Могут потребоваться установленный язык/интерпретатор Python (https://www.python.org/downloads/windows/) и библиотека PyQt5:

pip install pyqt5
